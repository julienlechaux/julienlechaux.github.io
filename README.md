# Personal webpage — Julien Lechaux

This folder is ready to be published with GitHub Pages.

## The three files you will edit most often

### 1. `site-data.js`
Edit:
- your name
- status
- institution
- email
- short introduction
- research interests
- HAL / arXiv / GitHub links
- news

### 2. `publications.js`
Add or edit publications and preprints.

### 3. `teaching.html`
Edit your teaching activities directly in this file.

## CV

Replace:

`assets/CV_Julien_Lechaux.pdf`

with your actual CV, keeping the same filename.

## Publish on GitHub Pages

1. Create a GitHub repository named:
   `YOURUSERNAME.github.io`
2. Upload all files from this folder to the root of the repository.
3. Push/commit the files.
4. The webpage will be available at:
   `https://YOURUSERNAME.github.io`

## Local preview

Open `index.html` in your browser.

## Main design file

The visual appearance is in:

`assets/style.css`

You normally do not need to modify it.
